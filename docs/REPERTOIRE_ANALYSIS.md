수집·분석일: 2026-08-27
대상: **예술의전당 콘서트홀 + IBK챔버홀**, **2016-01 ~ 2026-12 (11년)**
방법: 월간일정 API → 공연 상세페이지 → 곡목 파싱 → 정규화 → 빈도 집계

## 0. 결론 — 가설은 **반만 맞다**

사용자 가설:
> "한국에서 공연하는 클래식은 대부분 연주자만 달라지고 같은 곡을 연주한다.
>  임윤찬·손열음 같은 사람들이나 사람들이 모르는 곡을 친다."

**데이터가 말하는 것:**

| | 판정 | 근거 |
|---|---|---|
| **작곡가는 좁다** | ✅ **맞다** | 11년간 등장 작곡가 **188명**뿐. 상위 10명이 전체 연주의 **48.8%**, 상위 20명이 **67.4%**, 상위 30명이 **78.1%**. 지니계수 **0.774** |
| **작품은 좁지 않다** | ❌ **틀리다** | 고유 작품 **5,463곡**. 상위 100곡이 전체 연주의 **21.4%**밖에 못 덮는다. 50%를 덮으려면 **526곡**, 80%를 덮으려면 **2,847곡**이 필요하다. 지니계수 **0.515** |
| **레퍼토리가 고갈된다** | ❌ **틀리다** | 매년 **300~500곡**씩 새 작품이 들어온다. 11년을 봐도 포화되지 않는다 |
| **임윤찬은 희귀곡을 친다** | ✅ **맞다** | 본인 이름을 건 공연 기준 중앙 순위 **1413위** (코퍼스 중앙값 526위). 연주 2회 이하 희귀곡 비중 **50.0%** (전체 39.1%) |
| **손열음은 희귀곡을 친다** | △ **약하게 맞다** | 중앙 순위 **628위**. 코퍼스 중앙값(526)보다 약간 희귀한 정도 |
| **조성진은 희귀곡을 친다** | ❌ **틀리다** | 중앙 순위 **212위**, 희귀곡 비중 **18.9%**. 조사한 19명 중 가장 대중적인 축 |

**한 줄 요약: "같은 작곡가, 다른 곡"이다.**
베토벤·모차르트·브람스가 계속 나오는 건 맞지만, 그들의 *같은 곡*이 나오는 게 아니다.
그리고 "스타 연주자 = 희귀곡"도 일반화되지 않는다 — 임윤찬은 그렇고 조성진은 정반대다.

추가로, 곡목 라인은 뽑았지만 작곡가를 확정하지 못한 것이 **1,228개 (8.6%)** 있다.
이들도 집계에서 빠졌다. `rawText` 는 `parsed.jsonl` 에 전부 보존돼 있어 나중에 인덱스를 넓히면 되살릴 수 있다.

> **이 누락이 결론에 주는 영향은 한 방향이다.** 빠진 것은 대부분 **희귀·비서양·한국 창작** 곡이므로,
> 실제 레퍼토리 폭은 여기 측정된 것보다 **더 넓다.** "레퍼토리가 좁다"는 가설에 유리하게 편향된 데이터인데도
> 결과는 "좁지 않다"로 나왔다.

### 3-2. 이 표가 말하는 것

- **작곡가 축은 확실히 좁다.** 10명만 알아도 절반, 30명이면 4분의 3이다.
- 그런데 **같은 작곡가 안에서 곡은 흩어진다.** 모차르트는 1,011회 연주에 **334곡**, 베토벤은 1,163회에 **208곡**이다.
  즉 "베토벤을 또 한다"는 맞지만 "베토벤 5번을 또 한다"는 틀리다 —
  베토벤 최다 연주곡인 교향곡 5번도 11년간 **66회**로, 베토벤 전체 연주의 5.7%다.
- Verdi(167곡)·Puccini(122곡)·Bizet(106곡)·Rossini(102곡)처럼 **연주 횟수 대비 고유곡이 많은 작곡가**는
  갈라·아리아 프로그램이다. 오페라 아리아는 매번 다른 곡이 뽑힌다.

### 3-3. ⚠ 이 숫자의 한계

**(a) 188명은 실제보다 작다.** 작곡가 정규화 인덱스가
Open Opus 220명(영문 성) + 수동 한글 별칭 약 200종에 한정돼 있어,
**한국 창작곡·현대 위촉초연·비서양 작곡가는 통째로 빠졌다.**
"작곡가가 좁다"는 결론은 이 편향을 감안해도 성립하지만(빠진 것들은 어차피 롱테일),
**점유율 수치(48.8% 등)는 상한값**으로 읽어야 한다.

**(b) 동성(同姓) 작곡가가 합쳐져 있다.** 매칭 키가 성(surname)이라 다음이 한 사람으로 집계됐다:

| 합쳐진 키 | 실제로 섞인 사람 | 심각도 |
|---|---|---|
| `Strauss` (224회) | **요한 슈트라우스 2세**(신년 왈츠·폴카) + **리하르트 슈트라우스**(교향시·가곡) | **높음** — 성격이 완전히 다르다 |
| `Bach` (604회) | J.S. + C.P.E. + J.C. | 중간 (J.S.가 압도적) |
| `Schumann` (500회) | 로베르트 + **클라라** | 중간 |
| `Haydn` (228회) | 요제프 + 미하엘 | 낮음 |
| `Mozart` (1,011회) | W.A. + 레오폴트 | 낮음 |

이니셜 기반 분리 규칙은 `tools/sac_names.py` 의 `FAMILY` 테이블에 준비돼 있으나
현재 매칭 경로가 이를 타지 않는다. **`Strauss` 분리는 §6-3 계절성 해석에 직접 영향을 주므로

## 5. 연주자가 레퍼토리를 가르는가 — **가른다. 단, 방향이 사람마다 다르다**

### 5-1. 측정 방법

- 연주자 매칭은 **출연 크레딧에만** 한다 (공연 제목 / 출연진 라인 / 곡별 협연자 표기).
  남의 약력 산문에 이름이 언급된 것은 세지 않는다 — 이걸 세면 임윤찬이 40개 공연에 나오는 걸로 뻥튀기된다.
- **"헤드라인"** = 공연 제목에 이름이 들어간 공연. 프로그램을 본인이 고른 공연으로 본다.
- 지표: **중앙 순위**(전체 5,463곡 중 몇 위 곡을 치는가. 높을수록 희귀),
  **희귀곡 비중**(11년간 2회 이하 연주된 곡의 비율).

**코퍼스 기준선: 중앙 순위 526위 / 희귀곡 비중 39.1%**

2. **손열음은 미묘하다.** 628위로 기준선보다 약간 희귀한 정도다.
   단, 표본 75곡 중 상당수가 **모차르트 피아노 소나타 전곡 시리즈**다 —

   **전곡 완주라는 기획**이다. **빈도만으로는 이 둘을 구분하지 못한다** (§7 한계).
3. **조성진은 정반대다.** 212위, 희귀곡 18.9%. 임동혁(107위)·김봄소리·선우예권도 같은 쪽이다.
   협주곡 스타는 **오케스트라 정기공연의 표준 협주곡**을 맡는 자리라, 구조적으로 대중 레퍼토리에 묶인다.
4. **가장 희귀한 건 성악가다.** 황수미 2061위 — 가곡·아리아는 애초에 롱테일이다.
   이건 "도전적"이라기보다 **장르 특성**이다. 성악을 피아노와 같은 잣대로 비교하면 안 된다.
5. **표본이 작은 줄(최하영 5곡, 이혁 15곡)은 신뢰하지 말 것.** 참고로만 싣는다.

> **결론: "스타 = 희귀곡"은 일반화되지 않는다.** 임윤찬은 맞고 조성진은 틀리다.
> 오히려 갈리는 축은 **독주회냐 협연이냐**, 그리고 **장르(피아노/바이올린 vs 성악)** 다.

## 7. 이 데이터가 `WORK_TAGGING.md` 설계를 어떻게 바꾸는가

### 7-1. LLM 태깅 대상은 몇 곡으로 줄어드나 — **줄지 않는다. 늘려야 한다**

`WORK_TAGGING.md` §4 는 이렇게 적혀 있다:

> 24,975곡 전부 할 필요 없다. 한국 클래식 공연에 실제로 나오는 곡은 훨씬 적다.
> 상위 1,000 ~ 2,000곡 × 배치 50곡/요청 = 20~40 요청 → 하루면 끝

**이 가정을 데이터가 부정한다.**

| 태깅 대상 | 연주 커버리지 | "프로그램 전체를 아는 공연" 비율 |
|---|---|---|
| 상위 500곡 | 49.0% | 29.2% |
| 상위 1,000곡 | 61.9% | **42.5%** |
| 상위 2,000곡 | 73.5% | 56.1% |
| 상위 2,847곡 | 80.0% | — |

**상위 1,000곡을 태깅해도 공연의 57.5%는 "모르는 곡이 섞인 프로그램"이다.**
Open Opus 24,975곡을 다 할 필요는 없지만, **1,000곡으로는 부족하다.**

**권고 수정:**
- 1차 목표를 **상위 3,000곡**으로 올린다 (80% 커버리지). 배치 50곡 기준 60요청 — 여전히 하루 작업이다.
- 그 위에 **온디맨드 태깅**을 반드시 둔다. 사용자가 관람한 공연에 미태깅 곡이 나오면 그때 태깅해 캐시한다.
  **커버리지 100%를 배치로 달성하려는 설계는 이 분포에서 성립하지 않는다** (95%에 4,809곡 필요, 그중 72%는 1회성).
- **우선순위는 유지한다**: ① 사용자 이력 곡 → ② 빈출 상위 → ③ 나머지. 다만 ②의 N을 3,000으로.

### 7-2. `performerRarity` 는 빈도로 계산된다 — **확인. 바로 쓸 수 있다**

`WORK_TAGGING.md` §9 의 제안이 그대로 성립한다:

```
performerRarity(work) = 1 − (연주 횟수 / 최다 연주 작품의 횟수)
```

`app/data/repertoire.json` 의 각 작품에 **`count` / `rank` / `rarity`** 를 이미 넣어뒀다.
LLM에게 "이 곡이 희귀한가"를 물을 필요가 **전혀 없다.**

다만 **정규화 방식을 바꾸길 권한다.** 최다값(66회)으로 나누면 분포가 한쪽에 뭉친다
(72%가 1회 → rarity 0.985). **순위 백분위**가 낫다:

```
performerRarity(work) = rank(work) / 전체 작품 수      # 0=최빈, 1=최희귀
```
이러면 중앙값이 0.5 근처에 오고 축이 고르게 펴진다.
`repertoire.json` 에 **`rarityPct` 필드로 이미 계산해 넣었다.** `rarity`(최다값 정규화)는 참고용으로만 남겼다.

그리고 §9 의 연주자 지표도 계산됐다 (§5). **임윤찬은 실제로 희귀 레퍼토리를 고르고, 조성진은 아니다.**
`performerAdventurousness` 는 유효한 축이지만 **"스타인가"로 대리하면 안 된다.**

### 7-3. `innovation` 축 — 빈도가 대체하는 부분과 못 하는 부분

| `WORK_TAGGING.md` 의 축 | 빈도로 대체 가능한가 |
|---|---|
| **연주자의 도전** (`performerRarity`) | ✅ **완전히 대체된다.** LLM 불필요 |
| **작곡가의 도전** (`innovations[]`) | ❌ **전혀 대체 안 된다.** "베토벤이 포르테피아노의 확장된 음역을 전제로 썼다"는 연주 빈도와 무관하다 |

§9 에서 두 개념을 분리한 판단이 **데이터로 지지된다.** 실제로 상위 20곡(베토벤 5번, 9번,
라흐마니노프 2번…)은 **역사적으로는 극도로 혁신적인데 빈도로는 가장 흔하다.**
한 축으로 뭉갰다면 정확히 거꾸로 나왔을 것이다.

### 7-4. 작곡가 축을 1급 시민으로 — **가장 중요한 설계 변경**

작곡가 지니 **0.774** vs 작품 지니 **0.515**. 작곡가 축이 **훨씬 정보 밀도가 높다.**

- 상위 30명만 다루면 연주의 **78.1%** 를 덮는다. 작품으로 같은 커버리지를 얻으려면 **2,700곡**이 필요하다.
- `RESEARCH_data_sources.md` §5-4 의 "작곡가만이라도 먼저 잡아라"가 여기서 재확인된다.
  `concert_program.composer_id` 를 `work_id` 와 독립으로 채우는 설계는 **필수**다.
- **작곡가 단위 태깅(생몰·시대·국적·주요 형식)은 220명 × 1회면 끝난다.** 비용이 사실상 0이다.
  작품 태깅이 아무리 밀려도 작곡가 태깅만 있으면 취향 프로필의 뼈대는 선다.

### 7-5. 빈도로 **알 수 없는 것** — 정직하게

빈도는 다음을 **하나도** 알려주지 않는다. LLM/수동 태깅이 여전히 필요하다.

1. **"장조인데 슬픈"** — 사용자가 처음 제기한 바로 그 문제. `mood.valence` 는 빈도와 무관하다.
   쇼팽 녹턴 Op.27-2(28회, 34위)와 베토벤 5번(66회, 1위)의 정서 차이를 빈도는 표현하지 못한다.
2. **주제(`subject`)** — 자연인가 사랑인가 죽음인가. 빈도와 직교한다.
3. **짜임새(`texture`)** — 선율적/기교적/대위적. 빈도와 직교한다.
4. **작곡가의 도전(`innovations`)** — §7-3. 오히려 **음의 상관**에 가깝다(혁신작일수록 자주 연주된다).
5. **"희귀한 이유"** — 이게 가장 중요한 공백이다. 연주 횟수 1회인 곡이 3,942개 있는데,
   - (a) 어렵고 낯설어서 안 하는 곡
   - (b) 그냥 안 알려진 소품
   - (c) **전곡 시리즈의 한 조각** (손열음의 모차르트 소나타 전곡, 바흐 첼로 모음곡 6곡)
   - (d) 위촉 초연
   이 넷이 빈도상 **완전히 동일하게 보인다.** (c)를 (a)로 오독하면
   "이 분은 도전적인 레퍼토리를 좋아하시네요"가 엉뚱하게 나간다.
   → **최소한 (c)는 규칙으로 잡을 수 있다**: 같은 공연에서 같은 작곡가·같은 형식의 곡이 3개 이상 연속하면 전곡/연작 기획.
   §6-2 의 공동출현 데이터가 그 신호를 이미 갖고 있다.
6. **연주 해석** — 같은 곡도 지휘자마다 다르다. 이 데이터는 **작품** 단위이고 해석은 다루지 못한다.
7. **다른 공연장** — 이건 예술의전당 데이터다. 롯데콘서트홀·금호아트홀·세종문화회관의 분포는 다를 수 있다.
   특히 금호아트홀은 젊은 연주자 리사이틀 비중이 높아 롱테일이 더 길 가능성이 크다. **미수집.**

### 7-6. 계절성은 공짜로 얻은 축이다

`WORK_TAGGING.md` 에 없던 축인데 데이터가 강하게 지지한다.
`repertoire.json` 의 각 작품에 **`monthHist`(월별 연주 분포)** 를 넣어뒀다.

- 12월 = 베토벤 9번(그 곡 연주의 64%) + 호두까기인형 + 메시아
- 1월 = 요한 슈트라우스 (lift 최대 24배)
- 추천에 바로 쓸 수 있다: "12월에 합창 교향곡을 처음 들으셨네요" 같은 문장이 데이터로 뒷받침된다.
- 반대로 **계절 곡을 취향 신호로 오독하면 안 된다.** 12월에 9번을 들은 건 취향이 아니라 시즌이다.
  취향 벡터를 만들 때 **계절 lift가 높은 곡은 가중치를 낮춰야 한다.**

## 9. 남은 일

1. **합창·성악 인덱스 확장** — 한국 가곡·합창곡 작곡가(김동진·최영섭·이흥렬…) 사전을 추가하면
   실패한 290건 중 상당수가 살아난다. `parsed.jsonl` 에 원문이 남아 있으므로 **재수집 없이** 가능하다.
2. **이미지 프로그램 OCR** — 619건이 곡목을 이미지로만 싣는다. 이미 OCR 파이프라인이 있으므로
   `<img>` URL을 뽑아 돌리면 커버리지가 80% → 90%대로 오른다.
3. **다른 공연장** — 롯데콘서트홀·금호아트홀. 예당만으로 "한국 클래식"을 대표시키면 안 된다.
4. **전곡 시리즈 탐지 규칙** — §7-5 (c). 희귀도 해석의 정확도를 크게 올린다.
5. **동성 작곡가 분리** — §3-3 (b). `Strauss` 부터. 이니셜(`R.`/`J.`)과 곡 성격으로 갈린다.
6. **작품번호 세부 번호** — `Op.10 No.3` 같은 곡번호가 `op.10` 으로 뭉개지는 경우가 있다.
   쇼팽 에튀드·프렐류드처럼 세트 안에서 개별 곡을 뽑는 레퍼토리에서 과소 분리가 생긴다.
